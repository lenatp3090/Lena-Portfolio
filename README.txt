LENA T P — PORTFOLIO WEBSITE

HOW TO VIEW
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to preview the site in your browser.

BEFORE PUBLISHING — IMPORTANT EDITS
1. In index.html, replace YOUR_EMAIL@example.com with your real email address.
2. Add your resume PDF to the assets folder and add a Resume link if you want one.
3. Check every skill and keep only technologies you can confidently explain.
4. Verify the internship dates, degree details, project descriptions and GitHub links.
5. Add project screenshots to assets and replace the colored project artwork if desired.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository named lena-portfolio (or another name you prefer).
2. Upload index.html, style.css, script.js, README.txt and the assets folder.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. GitHub will show your published website URL in the Pages section.

This is a static HTML/CSS/JavaScript site and does not need a backend or paid hosting.
